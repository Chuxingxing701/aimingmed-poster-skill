# 艾名医学 AI 海报设计工作流

## 这是什么

把"碎片灵感需求、反复对话上下文"加工成"图像模型可直接执行的高质量出图 Prompt"的标准流水线。

核心思想：**你就是提示词工程师**——读参考图、清洗需求、列清单、一次性确认、写定稿 Prompt 全部由你完成；绘图模型只负责出图；先核对计划再写 Prompt，成本最低。

## 你的角色与能力分支

你端到端执行全部步骤，用户只在两个确认点拍板：Step 2 清单核对、Step 3 冲突确认。

| 能力 | 有 | 没有 |
| --- | --- | --- |
| 视觉读图 | 直接读本 skill 自带的两张参考图（见"附件"），按 Step 1 提取特征 | 用附件一节的文字描述打底，主动向用户索取缺失的视觉信息 |
| 图像生成 | Step 5 直接出图并按验收清单自验 | 交付定稿 Prompt + 交接说明，由用户拿到任意绘图工具执行 |

下游出图工具不限（GPT-image、libTV、即梦等均可），唯一要求：支持上传参考图作"画布参考/垫图"。

## 适用场景

- 艾名医学节点海报（如 5·20 国际临床试验日、11 月国际肺癌关注月）、医疗科普海报、品宣竖版长图
- 需求来自聊天记录式的碎片描述，指令之间互相矛盾（"不用做图"与"给我做图"并存、"不要文字"与给了三套文案并存）
- 参考图：一张排版/风格参考图 + 一张 IP 形象图（最好是四视图）。本 skill 已自带这两张图

**不适用：** 纯文字排版设计（无 AI 出图环节）；非艾名品牌项目（需整体替换"品牌资产速查"一节）。

## 总流程

```
用户/同事的碎片需求（聊天记录、矛盾指令）
   │
   ▼
Step 0  需求清洗 ── 剥离冲突指令、捞隐藏约束、统一装进"视觉元素"
   │
   ▼
Step 1  读参考图 ── 逐张描述排版/风格/形象特征，锁定图号职责，写 Prompt 草稿
   │
   ▼
Step 2  需求清单 ── 输出给用户逐项核对（本流程最有价值的产物）
   │
   ▼

   │

   │
   ▼
Step 5  出图验收 ── 能出图就出图+自验；不能就交付 Prompt + 交接说明
```

## Step 0 · 原始需求清洗

用户发来的需求通常是一堆聊天记录拼接，直接吃下去会带出三类事故：矛盾指令被照单全收、隐藏禁忌被长文本淹没、口语化指令干扰判断。**先清洗，再执行。**

- [ ] **剥离冲突指令**：把"帮我优化提示词（不用做图）"与"我现在要求你给我做一张图"、"不添加任何海报文字"与三套海报文案这类互相打架的口语指令，与纯视觉素材分离。冲突项不自行裁决，留待 Step 3 grill。
- [ ] **捞隐藏约束**：专门扫原始素材**末尾的补充吐槽**——核心禁忌最爱埋在最后（真实案例："类器官只要球状的，里面不需要密密麻麻的组织，一个球即可"）。
- [ ] **统一装填**：清洗后的素材全部归入"视觉元素"（主题、文案、尺寸、主体元素、配色、IP 要求、禁忌），作为 Step 1-2 的输入；执行规则由本流程定，不让原始话术带走控制权。

## Step 1 · 读参考图、写 Prompt 草稿（内部动作）

1. 读取本 skill 目录下的 `ref1-layout-style-520-poster.jpg`（排版/风格参考）与 `ref2-panda-ip-four-views.png`（IP 形象锚点）。无法读图时用附件一节的描述代替，并向用户确认关键视觉信息。
2. 逐张描述参考图：图1 说清排版特征、风格特征、Logo 与字体位置；图2 说清 IP 比例、服饰、配件。图号职责锁定：图1 管排版/风格/Logo/字体，图2 管 IP 形象。后续 Prompt 中凡引用参考图特征，必须显式标注"图1中的XX""图2中的XX"。
3. 将清洗后的视觉素材整理成一整段完整、极其详细的中文出图 Prompt **草稿**（连贯文段，不用分点符号）。草稿只是中间产物，不要当定稿发给用户。

## Step 2 · 需求核对清单（输出给用户逐项打勾）

这是整个流程**最有价值的产物**。素材可能有重复或矛盾，先去重再列。输出清单后请用户逐条核对，没过项修改重发，通过才进 Step 3。

| #   | 维度      | 核对项                                                                                                 |
| --- | ------- | --------------------------------------------------------------------------------------------------- |
| 1   | 画幅与文字策略 | 尺寸是否由绘图工具 UI 参数控制？是 → Prompt 中剔除像素数值。画面文字走 **AI 直出** 还是 **留白后期 PS**？定了才决定要不要把文案写进 Prompt            |
| 2   | 主题与文案   | 主标题/副标题/底部标语的最终字面锁定；写进 Prompt 的文案**两端加引号、句尾不加句号**；难画面化的医学名词做拆解（例："肺癌类器官"→ 球形类器官（主体）+ 人体肺器官（强辨识符号））  |
| 3   | 参考图职责   | 图号与职责一一对应（惯例：图1 管排版/风格/Logo/**字体**，图2 管 IP 形象）；Prompt 内引用显式标图号                                      |
| 4   | 主体视觉元素  | 核心主体的形态/质感/内部禁忌；动态流程元素清单；辅助线索的物理走向与功能（例：白色丝带贯穿画面 → 底部舒展承载文案）；IP 的站位/比例/装备/朝向**唯一锁定**，清除"可选""或者"等模糊词 |
| 5   | 场景与风格   | 渲染质感（3D/C4D）；背景虚化程度与背景元素清单；**真人策略**：完全去真人 / 允许真人（则需指定特征，如中国黄种人）/ 真人背影                               |
| 6   | 配色方案    | 主色+辅色明确；点缀色形态二选一：融入 3D 元素（如胶囊/高亮节点）还是平面色块；禁忌色写明（例：类器官内部无红色荧光）                                       |
| 7   | 品牌露出与禁忌 | Logo 位置唯一（优先跟随参考图1的成熟布局）；IP 形象不可改；禁忌清单完整（无真人/无乱码/无畸变/无多余元素）                                         |

## Step 3 · 一次性 Grill（冲突确认）

规则：**一次问完、每题给选项、用户只回选项字母**。不要分批追问，更不要自行裁决。

艾名项目高频冲突点（历史真实案例，供校准 grill 质量）：

| 冲突点     | 典型选项                               |
| ------- | ---------------------------------- |
| IP 站位   | A.左上角（易与标题/Logo 打架） B.左下角 C.中段实验台前 |
| IP 装备   | A.加护目镜+移液枪等道具 B.严格保持四视图原样          |
| 真人      | A.只要熊猫 B.真人+熊猫同框 C.仅真人背影           |
| Logo 位置 | A.跟随图1左上角 B.文字需求里写的右下角             |
| 文字策略    | A.纯留白后期 PS（最稳） B.AI 直出（需敲定唯一文案组合）  |
| 点缀色形态   | A.融入 3D 元素 B.平面色块/标签               |
| 矛盾指令    | "做不做图""要不要字"等原始素材内的打架指令，逐条列出拍板     |

## Step 4 · 出图 Prompt 定稿（你起草，用户过目）

原则：**一整段连贯文段**（方便改和看），内部按"总 → 分（顶部/中段/IP/底部）→ 收"分区叙述；文案一律引号包裹；禁忌写进描述而非另起一段。

骨架模板（`{占位符}` 按需替换）：

```text
这是一张{画幅与类型，如：竖版长图医疗科普海报}。整体视觉风格、{排版结构，如：上中下三段式排版}与{渲染质感，如：高端3D渲染质感（C4D/Octane Render）}深度参考图1。整体配色以{主色}与{辅色}为主。背景设定在{场景，如：现代感十足的科技蓝实验室}中，参考图1的{空间感/光影特征}，背景虚化呈现{背景元素：精密仪器、玻璃器皿、药品架等}。画面中{真人策略，如：不出现任何真人角色}。

顶部排版区域：{顶部布局参考，如：参考图1的顶部浅色留白布局}，{Logo位置}清晰放置图1中的艾名医学（AIMINGMED）官方红蓝Logo。顶部居中清晰排版主题大字："{主标题}"；大字下方紧跟小字配文："{副标题}"，字迹清晰端正、排版居中对称。

{方位}IP区域：在{位置}放置{比例，如：中等偏小}的熊猫医生IP形象，严格遵循图2的"艾名熊猫医生"四视图特征：二头身Q版比例、大圆头、黑眼圈配高光大眼、嘴角微扬，身穿左胸口印有艾名医学蓝色Logo的合身白色实验服{装备增减，如：，佩戴透明实验室护目镜，手持移液枪}，{动作朝向，如：正专注地朝向中央的球形类器官，展现药筛检测的互动感}。
```

> 不需要某分区就整段删除（如文字走留白 PS：删去所有 `"{文案}"` 句，改为"顶部/底部干净留白，不放任何文字"）。

## Step 5 · 出图与验收

### 5a · 环境内有支持垫图的出图工具

1. 把图1、图2 上传到出图工具的**画布参考/垫图**位，连同定稿 Prompt 一起提交。
2. 工具有画幅 UI 参数就在 UI 里设（如 1125×2436），Prompt 内不写像素值。
3. 画面文字：Prompt 中引号包裹、句尾不加句号；对工具的中文直出能力没把握就走留白 + 后期 PS（交付时向用户说明）。
4. 生成后按验收 checklist 自验：
   - [ ] 无乱码、无错字、无多字少字
   - [ ] 无画面畸变（多余手指/融化的脸/变形器械）
   - [ ] Logo 可辨认、位置正确
   - [ ] IP 还原四视图（比例、服饰、左胸 Logo）
   - [ ] 配色未跑偏、无计划外颜色
   - [ ] 文案与需求清单字面一致
   - [ ] 无禁忌元素（对照清单第 7 项）
5. 不通过：**只改对应分区的句子**重新生成，不重写整段。

### 5b · 无出图工具 —— 向用户交付三件套

1. **定稿 Prompt**：放在代码块里，方便整段复制；
2. **交接说明**：把 `ref1-layout-style-520-poster.jpg`、`ref2-panda-ip-four-views.png` 上传到绘图工具的画布参考/垫图位；画幅 1125×2436 在工具 UI 里设，Prompt 不写像素；文案两端引号、句尾不加句号；中文直出没把握就留白 + 后期 PS；
3. **验收 checklist**：同 5a 清单，让用户出图后对照。

## 常见坑（实战沉淀）

| 坑                   | 对策                                       |
| ------------------- | ---------------------------------------- |
| 用附录 C 元提示词不点明任务性质   | 首行写"本任务是文字工作，不要直接生成图片"（会画图的模型不说会直接出图） |
| 让 AI 直接生成 Prompt    | 先让它出需求清单核对，计划验证成本最低——你自己执行时也一样，别跳过清单直接定稿 |
| AI 挤牙膏式追问           | 强制一次性 grill，每题带 A/B/C 选项                 |
| 提示词工程交给视觉弱的模型       | 描述逻辑混乱、细节遗漏；此环节需要强视觉理解 + 中文写作能力          |
| 出图 Prompt 写成分点列表    | 必须是连贯文段（分点清单是中间产物，整段文段才是终稿）              |
| 引用参考图只说"参考风格"       | 必须显式"图1的XX""图2的XX"；排版和字体都要参考             |
| 类器官等同类物体过度描述        | "一个球即可"，写清形态和禁忌就够，别堆细节                   |
| IP 没有四视图直接进海报       | 先生成四视图，形象才有锚点                            |
| 文字引号/句号问题           | 绘图工具里文案两端加引号、句尾不加句号                      |
| 用户素材不过滤直接用          | 先做 Step 0 清洗——末尾吐槽里藏着核心禁忌                |
| "可选""或者"留在 Prompt 里 | IP 站位、装备、Logo 位置全部唯一锁定                   |
